# Issue #5: enable metrics in deployment

## Goal
Enable the app's built-in metrics listener in the Kubernetes deployment and document how to scrape it from the running service.

## Files to change
- `k8s/configmap.yaml` — set the metrics environment variables for the deployment
- `k8s/deployment.yaml` — expose the second container port named `metrics`
- `k8s/service.yaml` — expose the metrics port through the service
- `README.md` — add instructions for reaching the metrics endpoint

## Tests to add
- No new unit tests are needed; this is a manifest and documentation fix.
- Validation is the deployment smoke test and service health checks in the pipeline.

## Risks
- Missing `METRICS_PORT` while `METRICS_ENABLED=true` will crash the container at startup.
- Using a port that conflicts with another listener or the app port will fail config validation.

## Open questions
- None; the app already exposes a metrics listener, and the issue defines the desired port name and deployment behavior.
